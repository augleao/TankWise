NodeMCU ESP8266 board

NodeMCU v2 / ESP8266MOD (this firmware is for ESP8266, not ESP32).

Waterproof ultrasonic sensor kit

JSN-SR04T or AJ-SR04M set: control board + waterproof probe with cable.

2. Physical wiring

Wire the waterproof ultrasonic sensor to a NodeMCU ESP8266 (this firmware is for ESP8266, not ESP32).

  • VIN / 5V → VCC (JSN-SR04T needs 5V)
  • GND → GND
  • D3 (GPIO0) → Trig (inverted in firmware)
  • D4 (GPIO2) → Echo
  • Mount the sensor above the water, facing down, away from walls and foam.

3. Install firmware (USB)

Easiest path: open the TankWise installer page (Chrome/Edge), connect the NodeMCU by USB and flash in one click.

Install via USB (recommended) Download .bin Open ESPHome Web
  1. Connect the NodeMCU with a data USB cable
  2. In the installer, click Install and pick the serial port
  3. Or on web.esphome.io: Connect → Install → Choose the downloaded .bin
  4. After reboot, join the sensor Wi‑Fi hotspot and set your home network

Web Serial works in Chrome/Edge on a normal browser tab (not inside some iframes). Prefer the installer page opened above.
