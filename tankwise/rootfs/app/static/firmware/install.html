Instalar firmware do sensor

Conecte o NodeMCU ESP8266 ao computador via USB (cabo com dados). Use Chrome ou Edge.

  1. Conecte o NodeMCU na porta USB
  2. Clique em Instalar e escolha a porta serial
  3. Confirme a gravação e aguarde o fim
  4. Depois, configure o Wi‑Fi pelo hotspot do sensor (captive portal)
Baixar .bin Abrir ESPHome Web

Se o botão Instalar não aparecer, o navegador não suporta Web Serial. Baixe o .bin e use web.esphome.io (Connect → Install → Choose file).
